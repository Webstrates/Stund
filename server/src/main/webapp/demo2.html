Get access

The server demands an entityKey for every session request. Pick a name for yourself (each window of this demo is its own entity) and authorize once with the master password. The browser remembers one key at a time — the most recent login wins, so a second window that authorizes makes the first authorize again after its next reload. Until then, this page offers nothing but this box.
